# Life OS — моя траектория

Веб-приложение на русском языке для целей, самооценки и истории прогресса по всем сферам Life OS. Без установки зависимостей и без серверной базы данных.

## Запуск

Откройте `index.html` в современном браузере. Для постоянного использования удобнее статический веб-сервер или GitHub Pages: данные привязаны к адресу сайта и браузеру. При переносе между адресами используйте экспорт и импорт.

## Что внутри

- Радар баланса семи сфер и средняя самооценка от 0 до 10.
- Управление приоритетами: главный результат недели (Personal Chief of Staff).
- Измеримые цели с направлением, сроком и процентом выполнения.
- История оценок и график по отдельным сферам.
- Локальное сохранение, резервная копия JSON и проверяемый импорт.
- Изолированный демонстрационный режим, который не меняет личные данные.
- Адаптивный интерфейс для компьютера и телефона.

## Как считаются показатели

Самооценка отражает удовлетворённость, а не процент достижения целей. Средняя оценка считается только по заполненным сферам последней отметки; число заполненных сфер показывается отдельно. Частичные оценки отображаются отдельными точками на радаре, без выдуманных нулей. Для сравнения во времени желательно каждый раз оценивать одинаковый набор сфер.

Цели предполагают накопление результата от нуля: процент = текущее значение / целевое значение, максимум 100%. Для снижения веса или долга задавайте цель как количество сброшенных килограммов или погашенную сумму, а не остаток.

## Хранение и приватность

Приложение не отправляет оценки, заметки и цели на сервер. Используется `localStorage` текущего браузера. Нет аналитики, внешних шрифтов, сторонних скриптов или подключения к ChatGPT. История обсуждений и фактические личные показатели не включены в исходный код. Приложение изначально пустое; демонстрационные данные явно помечены.

Автоматического получения сведений из ChatGPT, банков, календарей или других сервисов в этой версии нет. Оценки и результаты вводятся вручную. Между устройствами переносите данные через экспорт и импорт. Очистка данных браузера удаляет локальные записи — сохраняйте резервную копию. Импорт заменяет данные после подтверждения.

## GitHub Pages

В настройках репозитория откройте **Pages → Deploy from a branch**, выберите основную ветку и папку **/(root)**. Сохраните настройки и дождитесь адреса, который выдаст GitHub. Репозиторий содержит готовые статические файлы; сборка не требуется.

## Разработка

`index.html` — структура, `styles.css` — оформление, `app.js` — данные, расчёты и взаимодействия. Синтаксическая проверка: `node --check app.js`.
